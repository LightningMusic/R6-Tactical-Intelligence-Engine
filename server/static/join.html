Before practice
  1. Pick the headset mic you use for Discord below (the first entry, "Default", is often a different device), then press Start. Your browser asks for the microphone once.
  2. Say something. The green bar on this page must move. If it doesn't, press Stop, pick another microphone and try again.
  3. Leave this tab open and the computer awake while you play. Minimize it, don't close it.
  4. That's it. It records when the host starts a match and stops when they stop.
