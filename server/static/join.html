One-time setup
  1. Press Start and allow the microphone when the browser asks.
  2. Say something: the green bar must move. If your microphone sends nothing, this page looks for one that works by itself.
  3. Leave this tab open and the computer awake while you play (minimize it, don't close it). The host starts and stops the recording.
  4. From now on, opening your link starts it by itself: there is nothing to press.
